# 参数手册 · 改哪个数会变成什么样

> 用 `./harness/build/export_spec > harness/ip-spec.json` 可以导出当前全部真实值。
> 这份文档讲的是**字段含义**，具体数值以导出结果为准。

---

## 一、配色 `Palette`（4 套）

一套配色 21 个颜色。不用全改 —— **改 3 个就够定调**：

| 字段 | 是什么 | 改它的效果 |
|---|---|---|
| `fur` | 主体毛色 | 决定这只宠物"是什么颜色" |
| `furShadow` | 耳、阴影（比毛色深一档） | 决定立体感。太深显脏，太浅没层次 |
| `bandana` | 围兜色 | **最容易出彩的一个**。用毛色的补色最跳 |

其余按用途分组：

| 组 | 字段 | 说明 |
|---|---|---|
| 毛色层次 | `furLight` `furLit` `furDeep` `furDark` | 高光/暗部。`fur*Light` 偏亮，`fur*Dark` 偏暗 |
| 斑纹 | `patch` `patchLit` `patchDk` | 耳朵和额纹 |
| 围兜 | `bandana` `bandanaDk` | 深色那档给褶皱用 |
| 眼色默认值 | `eyeL` `eyeR` | 瞳色选「跟形象」时用这两个 |
| 粉色系 | `pink` `pinkDeep` `pinkLit` `blush` `tongue` | 肉垫/腮红/舌头。`blush` 带透明度 |
| 描边 | `outline` `outlineDk` `dark` | 不建议改 —— 换色相会立刻"不像同一只猫" |

**改配色的顺序建议**：先定 `fur`（主色）→ 再挑 `bandana`（补色）→
`furShadow` 自动跟主色差一档即可。配色好的标准是"远看是一坨什么颜色"。

## 二、眼型 `EyeStyle`（9 档）

分两类：

| 类别 | 取值 | 参数 |
|---|---|---|
| **眼形** | 扁眼 / 圆眼 / 细长 | `squashY`（竖向压扁系数）、`stretchX` |
| **配件** | 墨镜 / 心形镜 / 星星镜 / 圆眼镜 / 单片镜 / 眼罩 | 无参数，覆盖在眼睛上 |

`squashY`：1.0 = 正圆，0.4 = 很扁。**瞳孔和高光不单独调** ——
它们按这个系数跟着走，所以加新眼形只要给这两个数。

## 三、瞳色 `EyeColor`（18 档）

- `auto` = 跟形象走（用配色里的 `eyeL/eyeR`）
- 12 个单色 + 3 组异色瞳（左右不同）+ 白 / 淡灰

**加新色的硬约束**：异色瞳那几组是差异化改造时定下的 —— 只用绿/青/紫/粉，
跟参考图的两个色系（灰蓝 ~205° / 棕金 ~38°）色相都拉开 ≥28°。加新色也守这条。

**白/淡灰**这类中性色有个坑：白色瞳孔会让白色高光消失，
所以代码里按亮度切了冷灰版高光（`lum > 0.94`）。

## 四、肚兜 `BibStyle`（4 档）

方兜 / 尖兜 / 圆兜 / 花边兜。

**名字不用手调位置** —— 代码直接居中在围兜路径的 `bounds` 里。
（早先是手写数字，尖角兜会把字顶到领口上，踩过。）

## 五、耳朵 `EarStyle`（4 档）

| 参数 | 含义 |
|---|---|
| `scaleW` / `scaleH` | 整体缩放 |
| `spread` | 两只耳朵往两边张开多少（绝对像素） |
| `tipKX` / `tipKY` | 耳尖位置（相对耳心，按头半径的比例） |
| `round` | 轮廓有多鼓：0 = 尖三角，1 = 圆顶 |

⚠️ **裁剪框是按最大那款耳算的**。做比它更大的耳型时，必须同步放大裁剪框，
否则头像里的耳尖会被切掉。

## 六、尾巴 `TailStyle`（5 档）

骨架是一串点 `spine`，相对**头心**的偏移，用 Catmull-Rom 串成平滑曲线。

```json
"curl": [[10, -48], [62, -74], [96, -30], [80, 8], [46, 0]]
```

- 点可以任意多个；4~5 个就够
- 半宽 = `base + extra · (1−u)^power`（u 从尾根到尾尖）
- **`up`（默认档）的数一个都不能动** —— 改了所有老用户的渲染都会变

加新尾巴：给 `spine` 就能看效果，宽度先沿用默认那组。

## 七、嘴形 `MouthStyle`（5 档）

`Geo` 结构，参数多但规律清楚：

| 部位 | 字段 | 单位 ⚠️ |
|---|---|---|
| 人中 | `philTop` `lipY` `philW` | ×s（绝对量） |
| 唇叶 | `spread` `c1x` `c2x` | **×cw（倍率）** |
| 唇叶 | `drop` `c1y` `c2y` `lobeW` | ×s（绝对量） |
| 下唇 | `hasLower` `lowHalf` `lowY` `lowCx` `lowCy` `lowW` | ×s |
| 张嘴 | `openWide` `openDeep` | 倍率（1.0 = 原样） |

**单位混用是这个结构最容易出错的地方** —— `spread` 是嘴宽的倍率，
`drop` 是像素量。改之前先确认你要调的是哪个。

唇叶是一条贝塞尔：`p0(0, lipY) → c1(c1x, c1y) → c2(c2x, c2y) → 末端(spread, drop)`。

### 待机微动（不是档位，是叠加项）

三个通道周期互质，凑不出规律：呼吸 4.6s / 抿唇 7.5s / 微张 11.3s。

**零值时必须是 IEEE754 精确恒等**（`x + 0.0`、`x * 1.0`），
这样关掉微动时表达式求值与原来**逐位相同**，默认档不用复制一份代码。

## 八、表情 `CatState`（13 个）

**分两类，这是踩过才知道的：**

| 类别 | 状态 | 特点 |
|---|---|---|
| 外观状态 | 待机 / 吃东西 / 开心 / 出错 / 疑惑 / 饿了 / 爱心 / 招手 / 困了 / 好奇 / 担心 / 没电了 | 改脸，静态可见 |
| 行为状态 | 被撸 | **不改脸**，只触发互动反馈（飘心、耳抖） |

### 加一个新表情

1. `enum CatState` 里**追加 case**（末尾）
2. 在绘制分支里加它的外观（改眼睛/嘴/眉毛的形状）
3. `./harness/build/render_sheet --dim state --out harness/out/state.png` 看区分度
4. `./harness/build/verify` —— 报"意外的重复"就说明跟某个旧表情撞脸了

### `--phase` 采样相位

`0` = 动作刚开始。做动效时固定相位才可复现，否则同一个表情两次渲染
可能采到不同瞬间，指纹就不稳。
