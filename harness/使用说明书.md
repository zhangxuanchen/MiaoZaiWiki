# 使用说明书 · 怎么用这套 Harness 做一个新 IP

> 配套文档：`萌宠IP生产Harness.md`（流程设计 / 节点清单 / 人机接口）。
> 这份是**操作手册** —— 每一步敲什么、哪些要你出面。

---

## 零、先知道三件事

**① 人只需要在 5 个地方出现**
给素材来源、看图选档、真机试用、确认合规、按发布键。
其余全是 AI 的活。

**② 你每次出面最好只做"选择题"**
不要说「嘴再圆一点」，要说「第 3 个」。AI 的职责是把判断变成可比较的图。

**③ 所有产物必须落在项目目录里，不能放 `/tmp`**
（这条有血证：2026-09-12 早上机器重启，`/tmp` 被清空，
那套跑了 190+ 条断言的测试脚手架一次性全丢。项目本身因为放在
`~/Documents/ai/` 才没事。）

## 一、环境要求

| 需要 | 用途 | 检查命令 |
|---|---|---|
| macOS 13+ | 目标平台 | `sw_vers` |
| Xcode 命令行工具 | `swiftc` 编译 | `xcode-select -p` |
| Python 3.8+（可重定位版） | 构建内嵌引擎 | `bash dist/make_engine.sh` 会自己找 |
| 约 1 GB 空闲磁盘 | 引擎 93 MB + DMG 50 MB + 中间产物 | `df -h ~` |

Python 那条要注意：**必须是可重定位的独立运行时**（带 `lib/libpython3.x.dylib`、没有 `pyvenv.cfg`）。
系统自带的 `/usr/bin/python3` 不行（它是 Xcode 的一部分，拷不走）。
推荐 [python-build-standalone](https://github.com/astral-sh/python-build-standalone) 的解压版。
脚本会按顺序找 `~/.workbuddy/binaries/python/versions/*`、`~/.local/python*`、`~/opt/python*`，
也可以直接指定：

```bash
MIAOZANG_PY_SRC=/path/to/python bash dist/make_engine.sh
```

## 二、一条命令做完的事

### 打包一个能发的 Mac 应用

```bash
cd ~/Documents/ai/MiaoZaiWiki
bash dist/build_app.sh
```

产出 `dist/release/喵藏-<版本>.dmg`。里面已包含：
App 本体 + 内嵌引擎（含 Python 解释器）+ 应用图标 + 给买家的安装说明。
出货前会自检四项：内嵌解释器可跑、主程序二进制无个人路径、引擎无个人路径、不含本机配置与书库。

可覆盖的参数：

```bash
MIAOZANG_VERSION=1.1.0 bash dist/build_app.sh
MIAOZANG_APP_ID=com.example.pet bash dist/build_app.sh
MIAOZANG_SIGN_ID="Developer ID Application: 你的名字 (TEAMID)" bash dist/build_app.sh
```

### 只重建内嵌引擎（改了 fetcher.py 之后要跑）

```bash
bash dist/make_engine.sh        # 约 1 分钟，产出 dist/.engine（93 MB）
```

### 本机开发用（装到 ~/Applications 并启动）

```bash
bash build.sh                   # 编译 + 安装 + 启动 + 注册开机自启
~/.catpet/catpet.sh status      # 看状态
~/.catpet/catpet.sh restart     # 重启
```

开发版和分发版**用的是两个不同的 bundle id**，可以同时装在一台机器上互不干扰。

## 三、八个阶段的操作清单

### 阶段 0 · 立项

**你要做的**：给一句方向 + 形象来源（图或描述）。

**AI 要做的**：
1. 反问澄清 —— 把模糊需求拆成 2~3 个可选项让你挑（**不要跳过这步**，省三轮返工）
2. 出 5 个候选名 + 取舍理由（推荐哪个、为什么、代价是什么）
3. 商标初查（**注意：只能查公开页，不等于商标局检索**）

**验收**：你能一眼看出选哪个，不需要 AI 再解释。

### 阶段 1 · 形象

**你要做的**：看对照图，说「第 3 个」。

**AI 要做的**：
1. 把形象拆成**参数**（不要写死数字），7 个维度各自成表
2. 每个维度出候选 → 渲染成**一张并排对照图**（不是 5 张图）
3. 落地后跑回归，证明**默认那档一个像素没动**

**验收**：对照图上每一款的差异肉眼可辨；改完之后渲染指纹与改动前一致。

### 阶段 2 · 视觉验证（你不需要参与）

**AI 必须有的四件套**：

| 能力 | 做什么 | 为什么必须有 |
|---|---|---|
| 离屏渲染 | 直接把视图渲成 PNG，**不靠截屏** | 截屏在无桌面会话时不可用，也没法精确控制尺寸 |
| 时间注入 | 指定时刻渲染（`renderTime = 5.775`） | 动画相位精确可复现，才能断言"微张那一刻" |
| 像素断言 | 数差异像素、算包围盒 | 「改了什么」和「有没有改坏」都要能量 |
| 指纹回归 | 整图哈希比对 | 一句话回答"默认档动没动" |

**验收**：改完一次绘制代码，能立刻回答"我只影响了嘴那 24×12 个像素"。

### 阶段 3 · 应用壳

**你要做的**：装上真机用几分钟，把不对劲的说出来。

**AI 要做的**：写探针脚本定位根因（不要靠猜），修完写进技能库。

> 这一阶段最容易被低估。像「输入框点不进去」这种问题，
> AI 写的所有断言都测不出来 —— 因为根因是 macOS 把**非活动窗口的第一次点击**
> 吃掉了，只有真人点才有现象。

### 阶段 4 · 引擎

**你要做的**：正常用它，喂点什么进去看看。

**AI 要做的**：引擎要 CLI 化（能脱离 UI 单独跑），并支持一条命令体检：

```bash
# 体检：能不能抓网页、书库在哪、编码对不对
<引擎>/python/bin/python3 <引擎>/fetcher.py --doctor

# 环境快照（JSON，方便 AI 读）
<python> fetcher.py --where

# 建书库 / 喂笔记 / 重扫
<python> fetcher.py --init-library "~/Documents/新书库"
printf '正文' | <python> fetcher.py --root <书库> --manual
<python> fetcher.py --root <书库> --rescan
```

### 阶段 5 · 合规（对外发之前必须过）

**你要做的**：确认素材来源（自绘 / AI 生成 / 委托画师 / 网上找的）——
**这件事 AI 永远查不出来**，它只能把证据摆给你看。

**AI 要做的**：
1. 依赖许可扫描（有没有 AGPL、GPL-only 这类传染性许可）
2. 源码里的"参考痕迹"扫描（有没有注释指向具体外部作品）
3. 原图比对（相似度 + 并排对照图）
4. 商标初查

**验收**：`侵权风险自查.md` 里每一项都有"结论 + 依据 + 残余风险"。

### 阶段 6 · 打包（纯自动）

见第二节。唯一要提醒的：**没有开发者证书时，买家第一次打开会被 Gatekeeper 拦**，
必须在下载页写清放行步骤（DMG 里已经带了一份 `首次打开请看这里.txt`）。

### 阶段 7 · 分发

**你要做的**：按下发布键、收款、回评论。

**AI 要做的**：文案 + 配图（1080×1440）+ skill 包 + 版权材料，一次出齐。

## 五、常见问题

**Q：改了 `fetcher.py`，App 里没生效？**
分发的 App 用的是**内嵌引擎**。要跑 `bash dist/make_engine.sh` 重建，再重新打包。
（本机开发版读 `~/.catpet/fetcher.py`，是另一条路径。）

**Q：DMG 打出来了，但用户说双击打不开？**
没签名/没公证的正常现象。让用户**右键 → 打开**，或在系统设置 → 隐私与安全性里点「仍要打开」。
想彻底解决就买 Apple 开发者账号（¥688/年）。

**Q：换一个 IP 要改哪些文件？**
现在还不太行 —— 7 个形象维度还在 `main.swift` 的枚举里。
先做 `harness/萌宠IP生产Harness.md` 第六节的第 1 项改造（抽 `ip-spec.json`）。

**Q：怎么知道 AI 改的东西没搞坏别的？**
看两样：渲染指纹（设定了默认档的哈希）+ 断言套件通过数。
两个都对上才算做完。

**Q：`main.swift` 已经 4856 行了，还要继续加吗？**
可以，但下一步应该先拆：
`PetRenderer`（绘制）/ `PetProfile`（配置）/ `PetPanel`（窗口）/ `Catalog`（书库）四个文件。
拆的时候**别改逻辑**，拆完跑一遍指纹确认没动到渲染。
