# 功能与安全风险说明

> 这份说明对应《最高人民法院关于依法审理涉人工智能纠纷案件的意见》
> （法发〔2026〕10号，2026 年 9 月 7 日发布）**第十三条**的要求 ——
> 该条规定：开源软件开发者、提供者以**免费开源**方式提供代码模块，
> **并公开说明其功能和安全风险**，他人使用该代码模块导致侵权的，
> 人民法院可以认定其不承担侵权责任。
>
> 「公开说明功能和安全风险」是获得该条款免责可能性的**必要条件**之一。
> 所以这份文件不是免责话术，是合规材料 —— 请随 skill 一起分发，不要删。

---

## 一、这份 skill 是什么

**它是一套方法论文档（开发流程 + 验证手段 + 踩坑记录），不是一个软件，
也不附带任何美术素材。**

| | 本 skill | 素材库 / 模板站 |
|---|---|---|
| 交付的是什么 | 方法、代码范式、验证思路 | 可直接使用的图片 / 模型 / 字体 |
| 含受版权保护的素材吗 | **不含** | 含（授权状态各异） |
| 用它产出的东西归谁 | 归使用者（代码是使用者写的、图是代码画的） | 视具体授权而定 |

## 二、它明确不做什么

- **不附带任何美术素材、字体文件、图标、模型。** 文档里的示例画面都是这套代码自己渲出来的。
- **不保证产出物合规。** 它教你**怎么查**（依赖许可、商标检索、素材来源、以图搜图），
  但不会替你查完 —— 也不会替你下结论。
- **不提供「照着某张图做同款」的指导。** 文档里讲差异化改造，方向恰恰相反：
  是教怎么让产出物离某个参照物更远。

## 三、已知限制与风险

1. **只适用 macOS。** 整条链路依赖 AppKit（`NSPanel` / `NSView` / `NSBezierPath`），
   Windows / Linux 跑不了 —— 这是能力边界，不是 bug。（要跨平台得换渲染栈，那是重写。）
2. **文档里的法条解读与合规建议，是工程视角的整理，不是法律意见。**
3. **「以图搜图」「商标检索」这两步必须由使用者本人执行** ——
   WebSearch ≠ 官方检索，检索要交互、要上传图片，脚本代替不了。
4. **引用第三方库的写法时，分发前要附许可声明。** 文档里有查许可的方法
   （读 `License-Expression` 而非 `License` 字段、避开 GPL/AGPL 传染项）。
