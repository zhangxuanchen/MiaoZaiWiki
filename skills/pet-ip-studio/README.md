# pet-ip-studio · 做一只 macOS 桌面宠物

装进 AI 助手（WorkBuddy / Claude Code / Codex 等吃 `SKILL.md` 规范的工具），
跟它说「**做一只柴犬的桌面宠物**」，它就会按固定流程做出来。

---

## 装到哪

| 你的 Agent | 装到 |
|---|---|
| WorkBuddy / CodeBuddy | `~/.workbuddy/skills/pet-ip-studio/` |
| Claude Code | `~/.claude/skills/pet-ip-studio/` |
| 其它 | 它的 skills 目录，**目录名保持 `pet-ip-studio`** |

```bash
# 解压到技能目录（macOS / Linux）
unzip pet-ip-studio.zip -d ~/.workbuddy/skills/
```

装好之后**不用记任何命令** —— 直接跟 Agent 说要做什么。

---

## 30 秒上手

```
你：做一只柴犬的桌面宠物，配色暖一点

Agent：好，先定三件事：
       ① 只要形象，还是也带别的功能？
       ② 配色方向（我出 3 套给你选）
       ③ 名字你定还是我出候选
```

它会自动：铺项目 → 出对照图 → 你挑一个 → 落地 → 验证 → 打包成 `.app`。
**你只负责看图、选一个。** 形象 + 表情做完大概来回 5~10 轮。

## ⚠️ 只支持 macOS

| 部分 | macOS | Windows / Linux |
|---|---|---|
| Agent 读流程、帮你改代码 | ✓ | ✓ |
| **渲染对照图 / 验证工具** | ✓ | **✗ 跑不了**（依赖 AppKit） |
| **产出的 app** | ✓ | **✗ 不行** |

**Swift 语言跨平台，AppKit 不跨。** 这套工具的核心是「把画面渲成图给你看」，
而渲染那一步离开 macOS 就没有了。

（如果你要的是「喂链接 → 自动归档」那个能力而不是桌面猫，用 `miao-zang` 那个 skill，
它在 Windows / Linux 上完整可用。）

## 它是怎么保证「改不崩」的

这套东西值钱的地方不是画法，是**验证**：

| 手段 | 回答什么问题 |
|---|---|
| `fingerprint --baseline` | 一行哈希 —— **默认档有没有被动过** |
| `verify` | 19 条断言 · 62 个档位：每档可区分、非空白、维度互不干扰 |
| `render_sheet` | 出并排对照图 —— 让人一眼挑，而不是让 AI 描述 |

**`fingerprint` 是关键**。人真正怕的不是"新功能坏了"（那看得见），
而是"新功能把旧功能悄悄碰坏了"（看不见）。指纹把"看不见"压成一行哈希。

实测过它真的会红：把默认档的一个颜色从 `0.985` 改成 `0.900`，
指纹立刻从 `29B2960CAB55A8D9` 变成 `86957E0FE0824359`，`--baseline` 报
「碰到了不该碰的地方」；改回来又绿。

## 做出来能干什么

- 4 套配色 × 9 种眼型（3 眼形 + 6 配件）× 18 种瞳色 × 4 肚兜 × 4 耳型 × 5 尾巴 × 5 嘴形 × 13 表情
  = **259,200 种组合**
- 编译成 `.app` 双击就能在桌面上养
- 拖动、右键菜单、多只猫互动，模板里都有

### ⚠️ 但要说清：模板画的是**一只猫**

模板（`assets/PetApp.swift`）里的形状是猫的形状 —— 有胡须（`drawWhiskers`）、
猫耳（`drawEar`，4 档都是猫耳：尖耳/圆耳/折耳/大耳）、猫的三瓣嘴（`drawCatMouth`）、
肉垫（`drawPawPrint`）。

所以「做一只柴犬」默认得到的是一只 **柴犬配色的猫**。这不算骗人 ——
配色、眼睛、尾巴、表情确实都换了，但**轮廓还是猫**。

**要换成别的物种，得让 Agent 改绘制代码**（删胡须、把耳朵改成垂耳、
把吻部拉长成狗嘴、换尾巴形状）。这些都能做 —— 全是贝塞尔曲线，而且模板里
每个部件都是独立函数，改一个不影响别的 —— 但那是**真的写代码**，
不是调参数。而且改完指纹会变（这是**正常的**：换物种本来就该变；
指纹要守住的是「你没打算改的地方别动」）。

判断依据很简单：

| 你想要 | 走哪条路 |
|---|---|
| 换配色 / 眼睛 / 尾巴 / 嘴形 / 表情 | 调参数，几轮就好 |
| 换姿势、加配饰、加新表情 | 加绘制函数，中等工作量 |
| **换成狗 / 兔 / 狐狸** | 改绘制函数（轮廓级），工作量大得多 |


**不含**：书库抓取那套功能（那需要额外把 93 MB 的 Python 运行时打进 bundle）。
要那个的话是另一个项目的事。

## 用之前请想清楚的三件事

1. **形象必须是自主的** —— 自己画的 / AI 生成的 / 委托画师（要有书面约定著作权归你）。
   **不要用网上随手存的图**，哪怕只是"参考着画"。
2. **名字查一下商标** —— 中国商标网，第 9 类（软件）+ 第 42 类（设计开发）。
3. **图标用你自己的** —— `pack_app.sh --icon 你的图.png`（1024×1024）。

详见 `references/pitfalls.md`。
